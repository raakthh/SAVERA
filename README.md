# SAVERA

## Smart Automotive Vehicle Evaluation and Repair Assessment

SAVERA is a web-based system designed to help automotive workshops
manage vehicle damage assessment, repair planning, inventory,
PPIC, and data analytics.

## Main Features

- Vehicle Damage Assessment
- Computer Vision
- Damage Severity Analysis
- Repair / Replace / Repaint Recommendation
- Repair Cost Data Analysis
- Inventory Management
- PPIC & Reorder Recommendation
- Repair Queue Management
- Revenue Analytics
- Customer Dashboard
- Workshop Dashboard
